<objective>
Two view-model defects from the audit scan.

Item 1 — the startup prompt can be lost: the status sweep starts in the constructor, App arms the
prompt only after `await vm.ReportLoad()`, and ReportLoad awaits a reachability probe on every
load with a configured backup root. A sweep that settles during that await finds the prompt
un-armed; the prompt then fires on the next full sweep, mid-session. Fix: record "first full sweep
settled" and evaluate immediately on arming when it already has.

Item 2 — a row action can run beside "Back up selected" while its folder probe or picker is open:
RunBulkBackupAsync awaits EnsureBackupRootAsync before anything is guarded, so row Backup, Refresh
and Change backup folder stay enabled, and a row backup can delete the bulk run's in-flight
staging file. Fix: a guard raised before the await, counted in IsAnyOperationRunning.

Output: MainViewModel changes, an App comment fix, reordered and new facts, two CHANGELOG bullets.
Two commits. Item 2 precedes item 14 (Plan 02-08). Spec-less probe fallback skipped: the phase
has no requirement IDs to probe (visible skip).
</objective>
