# Ein Spiel hinzufügen, das Scan nicht findet

**Scan** erkennt nur Spiele, die bereits bekannt sind, und diese Liste ist eine feste
Momentaufnahme — sie veraltet, sobald Spiele aktualisiert werden oder ihren Spielstand-Ordner
verschieben. Wenn Scan ein Spiel übersieht, oder sich der Speicherort eines bereits verfolgten
Spiels geändert hat, nutzen Sie Folgendes.

## Ein neues Spiel manuell hinzufügen

1. Klicken Sie in der Symbolleiste auf **Add game** — es öffnet sich der Dialog **Add game**.
2. Füllen Sie **Name** und den Spielstand-Ordner aus.
3. Falls Sie nicht sicher sind, wo ein Spiel seine Spielstände speichert, nutzen Sie den Link
   **Find game on PCGamingWiki** im Dialog — dort sind die Speicherorte der meisten Spiele
   dokumentiert, auch für Spiele, die nicht in SavegameBunkers integrierter Liste stehen.
4. Klicken Sie zum Bestätigen auf **Add**.

## Per Drag & Drop

Ziehen Sie einen Spielstand-Ordner aus dem Explorer auf das SavegameBunker-Fenster. Dadurch öffnet
sich der Dialog **Add game** mit diesem Ordner bereits eingetragen — Sie müssen nur noch den
Namen eingeben.

## Ein Spiel hat seinen Spielstand-Ordner geändert

Öffnen Sie **More actions** ("⋯") in der Zeile dieses Spiels und wählen Sie **Change save
folder**, anstatt das Spiel zu entfernen und neu hinzuzufügen — so bleiben die vorhandenen
Sicherungen mit demselben Eintrag verknüpft. Wählen Sie im sich öffnenden Dialog den neuen Ordner
und klicken Sie auf **Update folder**.

## Den Spielstand-Ordner eines Spiels öffnen

**More actions** ("⋯") enthält auch **Open save folder**, das den Spielstand-Ordner dieses
Spiels direkt im Explorer öffnet.

## Ein Spiel aus der Liste entfernen

**More actions** ("⋯") enthält außerdem **Remove from list**. Das entfernt nur den Eintrag aus
SavegameBunker — Ihre Spielstand-Dateien und bereits erstellte Sicherungen bleiben unverändert auf der
Festplatte.
