# Tastenkombinationen

| Tastenkombination | Aktion |
|---|---|
| **Ctrl+B** | Sichert die gerade fokussierte Zeile |
| **Ctrl+R** | Stellt die gerade fokussierte Zeile wieder her |
| **Alt, A** | **Add game** |
| **Alt, S** | **Scan** |
| **Alt, R** | **Refresh** |
| **Alt, O** | **Open the games list** |
| **Alt, C** | **Change backup folder** |
| **Alt, B** | **Back up selected** |
| **Alt, T** | **Restore selected** |
| **Alt, H** | **Help** |

Drücken Sie zuerst **Alt**, dann den Buchstaben — jeder Buchstabe ist auch auf der Beschriftung
der zugehörigen Schaltfläche unterstrichen. **Back up all changed** und **Switch theme**
haben keine Alt-Tastenkombination; nutzen Sie dafür Maus oder Tab.

Alle Dialoge in SavegameBunker bleiben auch bei größeren Windows-Textgrößen bis 150 % lesbar und
nutzbar, sodass diese Tastenkombinationen auch bei hochskalierter Anzeige weiter funktionieren.
