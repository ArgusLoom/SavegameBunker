{#- Language switcher for the offline help pack. The help// trees ship inside the release zip and are opened via file://, where a root-absolute link ("/en/") resolves against the drive root of the opened file (file:///D:/en/) instead of the pack root. So the switcher must never render a path href: each entry carries its target language in data-gv-lang and a delegated click handler rewrites the current pathname, which keeps the switch working at any nav depth (index, how-to/*, reference/*) and for both builds, since the handler derives the target from the URL. Markup otherwise mirrors the upstream zensical_ui partial, so the dropdown styling (md-select) stays intact. -#}
