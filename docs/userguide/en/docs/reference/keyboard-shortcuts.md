# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| **Ctrl+B** | Backs up whichever row is currently focused |
| **Ctrl+R** | Restores whichever row is currently focused |
| **Alt, A** | **Add game** |
| **Alt, S** | **Scan** |
| **Alt, R** | **Refresh** |
| **Alt, O** | **Open the games list** |
| **Alt, C** | **Change backup folder** |
| **Alt, B** | **Back up selected** |
| **Alt, T** | **Restore selected** |

Press **Alt** first, then the letter — each letter is also underlined on its button's label.
**Back up all changed**, **Switch theme** and **Help** have no Alt mnemonic; use the mouse or Tab to reach
them.

All dialogs in SavegameBunker stay readable and usable at larger Windows text sizes, up to 150%, so
these shortcuts keep working even if you've scaled up your display's text size.
