# Back up your saves

## Back up everything that changed

Click **Back up all changed** in the toolbar. SavegameBunker backs up every game whose **Status**
shows play not backed up yet, plus every game that was never backed up. Games that are already up
to date are skipped.

## Back up specific games

1. Check the box on each row you want, or use the header checkbox to select or clear every
   visible game at once.
2. Click **Back up selected**.

Only the checked games are backed up, regardless of their status.

## Back up a single game

Click **Back up** on that game's row. This works whether or not the game is selected.

## Watching progress

Large backups show a progress bar that fills as bytes are actually written, not just a spinner.
Before the backup starts, SavegameBunker shows a free-space hint comparing the backup folder's free
space to what's about to be copied. This is informational only — it never blocks or warns you off
a backup, so a tight backup folder won't stop you.

## Keyboard shortcut

**Ctrl+B** backs up whichever row is currently focused — no mouse needed.

## If there's no backup folder yet

The first time you back up, SavegameBunker asks where to put backups and remembers your answer. See
[Change the backup folder](change-the-backup-folder.md).
