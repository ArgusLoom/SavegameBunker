# Add a game Scan doesn't find

**Scan** only recognizes games it already knows about, and that list is a fixed snapshot — it
goes stale as games update or move their save folder. If Scan misses a game, or a game you
already track changed its save location, use these instead.

## Add a new game manually

1. Click **Add game** in the toolbar — this opens the **Add game** dialog.
2. Fill in **Name** and the save folder.
3. If you're not sure where a game keeps its saves, use the dialog's **Find game on
   PCGamingWiki** link — most games' save locations are documented there, including for games not
   in SavegameBunker's built-in list.
4. Click **Add** to confirm.

## Drag and drop

Drag a save folder from File Explorer onto the SavegameBunker window. This opens the **Add game**
dialog with that folder already filled in, so you only need to type the name.

## A game changed its save folder

Open **More actions** ("⋯") on that game's row and choose **Change save folder**, rather than
removing and re-adding the game — this keeps its existing backups attached to the same entry.
In the dialog that opens, pick the new folder and click **Update folder**.

## Opening a game's save folder

**More actions** ("⋯") also has **Open save folder**, which opens that game's save folder
directly in File Explorer.

## Removing a game from the list

**More actions** ("⋯") also has **Remove from list**. This only removes the entry from
SavegameBunker — your save files and any backups you've already made stay exactly where they are on
disk.
